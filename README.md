# WMAZING Landing

Лендинг онлайн-игры **WMAZING Online** на Angular.

## Требования

- Node.js **18+** (рекомендуется 20 LTS)
- npm **9+** или yarn / pnpm
- Angular CLI (установится глобально или локально)

Проверить версии:

```bash
node -v
npm -v
```

## Установка

1. Клонируй репозиторий (или просто открой папку проекта):

```bash
cd wmazing
```

2. Установи зависимости:

```bash
npm install
```

Если используешь yarn:

```bash
yarn
```

## Запуск в режиме разработки

```bash
ng serve
```

или

```bash
npm start
```

После запуска открой в браузере:

```
http://localhost:4200
```

Приложение автоматически перезагружается при изменении файлов.

### Полезные флаги

```bash
ng serve --port 4300          # другой порт
ng serve --open               # сразу открыть браузер
ng serve --host 0.0.0.0       # доступ по сети
```

## Сборка для продакшена

```bash
ng build
```

или

```bash
npm run build
```

Готовые файлы появятся в папке:

```
dist/wmazing/browser
```

Для запуска production-сборки локально можно использовать любой статический сервер, например:

```bash
npx serve dist/wmazing/browser
```

## Как добавлять новые секции

1. Создай компонент:

```bash
ng g c components/название --standalone --style=scss
```

2. Добавь его в `app.ts` → `imports`

3. Вставь в `app.html`:

```html
<app-название />
```

## Картинки

Все статические изображения лежат в `public/`.

- Путь в коде начинается с `/`  
  Пример: `/pages/logo.png` → файл `public/pages/logo.png`

- Галерея: `public/pages/gallery/`
- Features: `public/pages/features/`
- Иконки: `public/icon/`

После добавления новых картинок в галерею — пропиши их имена в массивах `row1 / row2 / row3` внутри `gallery.ts`.

## Шрифт

Используется **Roboto** (подключается через Google Fonts в `styles.scss`).

## Технологии

- Angular (standalone components)
- SCSS
- TypeScript
- CSS animations + requestAnimationFrame (прогресс-бар features)

## Возможные проблемы

**Ошибка `'app-xxx' is not a known element`**  
→ Забыл добавить компонент в `imports` у `App`.

**Картинки не грузятся**  
→ Проверь, что файл лежит в `public/` и путь начинается с `/`.

**Хедер дёргается при скролле**  
→ Пороги сворачивания настроены в `header.ts` (сейчас 40 / 120 px).

**Галерея появляется с пустотой**  
→ Нужно продублировать массив картинок несколько раз (уже сделано ×4).

## Дальнейшая разработка
